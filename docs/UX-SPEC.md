# sbpanel 交互与体验规格 v1

> 视角：产品 + 交互设计。视觉风格沿用 doona（Rosé Pine、扁平卡片、胶囊按钮），**交互模式**则参考更成熟的管理后台：Remnawave / PasarGuard（代理面板的用户管理）、Linear（键盘优先、命令面板、批量操作）、Vercel / Stripe Dashboard（状态反馈、抽屉详情、空状态）。
> 每条都带优先级 **P0 / P1 / P2** 和验收标准。实现以 P0 为必须项。

---

## 0. 现状问题（review 结论）

1. **动效几乎没有**：抽屉、弹窗、命令面板、下拉、Toast 只有一个统一的 `pop` 进场动画，**没有出场动画**（关闭时瞬间消失）；抽屉不是从侧边滑入；Tabs 和 Segmented 的选中态直接跳变；整体显得生硬，缺少空间感。
2. **用户管理只是能用**：没有批量操作，没有常用筛选（即将到期、额度快用完），排序只有一种，常用操作（复制订阅、续期、加流量）都要打开抽屉再点好几步，创建完用户还要自己去找订阅链接。
3. **操作反馈不闭环**：保存后只提示「正在下发到节点」，之后有没有生效看不到；开关类操作要等接口返回才变化，体感迟钝；复制只靠 toast 反馈。
4. **缺少「需要处理什么」的入口**：概览只罗列数据，没有把离线节点、下发失败、即将到期、快超额的用户集中起来。
5. **节点接入是一次性弹窗**：复制命令之后只能自己猜节点有没有连上。

## 1. 动效系统（P0）

### 1.1 Token（写进 `index.css`）
| token | 值 | 用途 |
|---|---|---|
| `--dur-1` | 120ms | hover、按下、颜色变化 |
| `--dur-2` | 180ms | 下拉、菜单、Toast、Tabs 指示条、出场动画 |
| `--dur-3` | 260ms | 抽屉、弹窗、命令面板进场 |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 进场（快速出现、缓慢落定） |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 出场 |
| `--ease-std` | `cubic-bezier(.45,0,.4,1)` | 位移类过渡（指示条、拇指） |

规则：**进场慢，出场快**（出场时长约为进场的 70%）；只对 `transform` / `opacity` 做动画；`prefers-reduced-motion: reduce` 下所有位移动画改成 120ms 淡入淡出（不要直接去掉反馈）。

### 1.2 组件动效（react-aria-components 会在 `data-entering` / `data-exiting` 状态上等 CSS 动画播完再卸载，**必须同时写进场和出场**）

| 组件 | 进场 | 出场 | 验收 |
|---|---|---|---|
| **Drawer（用户详情等）** | 遮罩 opacity 0→1（dur-3）；面板 `translateX(100%)`→0（dur-3，ease-out），内容区延迟 60ms 淡入 | 面板滑出到 `translateX(100%)` 并同时淡出遮罩（dur-2，ease-in） | 打开和关闭都能看到滑动；连续切换用户时面板**不重新滑入**，只是内容交叉淡入 |
| **Drawer 手机端（<640px）** | 变成底部 sheet：`translateY(100%)`→0，顶部有拖拽把手，圆角 20px，最高 92vh | 向下滑出 | 360px 宽可用，内容可以滚动 |
| **ModalDialog** | 遮罩淡入；面板 `scale(.96) translateY(8px)`→1（dur-3） | `scale(.98)` 加淡出（dur-2） | 关闭不再瞬间消失 |
| **命令面板 ⌘K** | 遮罩淡入；面板从 `translateY(-8px) scale(.98)` 落下（dur-2） | 淡出加 `scale(.98)` | 选中项背景是**一个**跟随移动的高亮块（transform 过渡，dur-1），不是每行各自闪变 |
| **Popover / Select / Menu** | 从触发点方向展开：`transform-origin` 指向触发器，`scale(.96)` 加 opacity（dur-2） | 淡出（120ms） | 下拉不再「啪」地出现 |
| **Toast** | 从底部 `translateY(12px)` 加淡入；多条时向上推叠 | 淡出加下移 | 带图标；错误类停留 6 秒且可手动关闭；**可带操作按钮**（例如「撤销」） |
| **Tabs** | 下划线指示条在 tab 之间滑动（宽度和位置做过渡，dur-2，ease-std） | — | 切换时指示条平滑移动 |
| **Segmented** | 选中的白色拇指在选项之间滑动 | — | 同上 |
| **侧栏导航** | 左侧 3px 选中条在条目之间滑动（doona 做法） | — | 切换页面时选中条滑到新位置 |
| **页面切换** | 内容 opacity 加 `translateY(4px)`→0（dur-2） | — | 已有 fade，加上位移 |
| **列表增删** | 新建或刚修改的行用 accent 10% 背景高亮，1.2 秒内淡出；删除的行先淡出再移除 | — | 创建用户后能一眼看到新行 |
| **Skeleton → 内容** | 交叉淡入，没有布局跳动（骨架高度和最终内容一致） | — | — |
| **数字** | KPI 数值变化时短暂淡入，不做滚动计数 | — | 不抖动；数字使用 tabular-nums |
| **复制按钮** | 图标变成 ✓ 并显示「已复制」，1.5 秒后恢复（不再弹 toast） | — | 所有 CopyText |
| **Switch / Checkbox** | 拇指滑动（已有）；勾选图标 scale .6→1 | — | — |

## 2. 用户管理（参考 Remnawave / PasarGuard 的用户页 + Linear 的列表）

### 2.1 列表（P0）
- **筛选条**（URL 同步，刷新后保留）：
  - 搜索：防抖 150ms；匹配用户名、备注、UUID 前缀；按 `/` 聚焦。
  - 筛选 chips（可多选，chip 上显示数量）：`全部` `在线` `即将到期（≤7 天）` `额度 ≥80%` `超额` `已过期` `已禁用` `从未使用`。
  - 分组下拉。
  - 排序：用量、到期时间、最近在线、创建时间、用户名；表头点击排序，显示箭头。
- **行信息设计**：
  - 用户名 + 备注（第二行灰色）
  - 状态 pill
  - 用量条：显示「已用 / 总量 · %」，80% 变黄，95% 变红
  - 到期：显示**相对时间**（「3 天后」「已过期 2 天」），悬停显示具体日期；7 天内到期标黄
  - 在线：绿点加设备数（有上限时显示 `2/3`）
  - 最近在线：相对时间
- **行内快捷操作**（悬停或键盘聚焦时出现，手机端放进行尾的「⋯」菜单）：
  - 复制订阅链接
  - 二维码（popover 展示）
  - 「⋯」菜单：续期 +30 天、+100GB、重置用量、启用/禁用、断开连接、删除
- **批量操作**：
  - 行首复选框；表头可以全选**当前筛选结果**；支持 shift 点选一段范围。
  - 选中后，底部滑出一条**批量操作栏**（dur-3），显示「已选 N 个」和这些按钮：启用、禁用、续期…、增加流量…、重置用量、设置分组…、复制订阅链接（按行合并）、删除。
  - 删除时需要输入数量确认。
  - 后端新增 `POST /api/users/batch {ids, action, value}`。action 取值：`enable` `disable` `extend_days` `add_traffic` `reset_usage` `set_groups` `delete`。在一个事务里完成，只触发一次 reconcile，记录审计日志并返回影响的行数。**要有测试。**
- **键盘**：`j` / `k` 上下移动焦点行，`Enter` 打开详情，`x` 选中，`⌘A` 全选筛选结果，`Esc` 取消选择。
- 用户数超过 200 时使用虚拟滚动，或分页（每页 100）。（P1）
- **空状态**：没有用户时显示引导（新建用户 / 批量创建 / 从 3x-ui 迁移三个入口）；有用户但筛选结果为空时，提供「清除筛选」按钮。

### 2.2 详情抽屉（P0）
- **头部固定**，包含：
  - 用户名、状态
  - 主操作：复制订阅链接、二维码、编辑
  - 「⋯」菜单：重置用量、更换密钥、断开连接、删除
  - **上一个 / 下一个**按钮（快捷键 `j` / `k`），在当前筛选结果里切换；切换时抽屉不关闭，只交叉淡入内容
- **续期快捷区**（Remnawave 和 Marzban 的高频操作）：额度和到期旁边放 chips，`+7 天` `+30 天` `+90 天` `+50GB` `+100GB` `不限`，点一下立即生效，同时 toast 提供「撤销」。
- 启用开关采用**乐观更新**：立刻切换，失败再回滚并提示错误。
- 当前 tab 写进 URL（`?id=1&tab=sub`），刷新后不丢。
- 订阅 tab 首屏直接显示订阅链接加二维码，其余格式折叠起来。

### 2.3 新建用户（P0）
- 表单顶部放**套餐预设 chips**：`试用（10GB / 7 天）` `标准（100GB / 30 天 / 月重置）` `不限`。点击后自动填写；仍然可以手动改。
- 额度输入框带单位切换（GB / TB）；到期提供快捷项（7 / 30 / 90 / 365 天、永久）和日期选择。
- **创建成功不要直接关闭弹窗**：切换到「创建成功」状态，显示订阅链接、二维码、「复制链接」和「再建一个」两个按钮，以及「查看详情」。（这是最常见的下一步。）
- 内联校验：用户名非法或重复时，在字段下方实时提示（重复检查在提交时做即可）。

### 2.4 其它
- 「用户自助页」入口：抽屉订阅 tab 里给一个「在新窗口预览」。（已有，保留）
- 批量创建完成后同样显示结果：创建了 N 个，提供导出（CSV：用户名、订阅链接）。（P1）

## 3. 全局反馈闭环（P0）

- **配置同步状态指示器**（顶栏，参考 doona 的「apply N held changes」和 Vercel 的部署状态）：
  - 全部节点 `applied_revision == revision` 且都在线：灰色「已同步」。
  - 有节点正在应用：蓝色「同步中…」，带旋转点。
  - 有节点下发失败或离线：红色「1 个节点异常」，点击打开 popover，列出异常节点和错误，并给出跳转链接。
- **保存后的生效提示**：触发 reconcile 的保存（用户、分组、入站、模板）完成后，toast 先显示「已保存 · 正在下发到 N 个节点」；等节点追上新 revision，**原地更新**为「✓ 已在所有节点生效」；15 秒仍未完成时提示去查看节点。前端实现方式：保存后 3 秒内每 1 秒轮询一次 `/api/nodes`。
- **按钮 pending 态**：提交类按钮在请求期间显示 spinner 并防止重复提交（统一放进 `Button isPending`）。
- **撤销**：可逆操作（禁用、续期、加流量、批量启用/禁用）的 toast 带「撤销」按钮，8 秒内有效，点击后调用逆操作。

## 4. 概览：先告诉我哪里有问题（P0）

- KPI 下方加一张**「需要关注」**卡片，只在有内容时显示。每一项都是可点击的链接，直接跳到筛选好的列表或节点：
  - 离线节点、下发失败的节点
  - 节点月流量 ≥80%
  - 7 天内到期的用户（N 个）
  - 额度 ≥80% 的用户（N 个）
  - 今天新出现的 IP（如果有）（P1）
- 全部正常时显示一行绿色的「一切正常 · N 个节点在线 · 最近 5 分钟 ↓x ↑y」。

## 5. 节点接入向导（P0）

- 「添加节点」改成三步向导，**在同一个弹窗里推进**：
  1. 名称和公网地址
  2. 接入命令：一键复制；给两种方式：一键安装脚本（推荐），或手动 enroll 加 run
  3. **自动检测**：每 2 秒轮询一次节点状态，依次显示「等待节点接入…（脉冲动画）」→「已签发证书 ✓」→「已连接 ✓ · sing-box 1.14.4」→「完成」。完成后提供「为它创建入站」按钮，跳到入站页并预选这个节点。
- 令牌过期时，在向导里直接给「重新生成」按钮。

## 6. 入站创建（P1）

- 协议模板从下拉框改成**卡片网格**：每张卡片有图标、名称、一句话说明（例如「REALITY · 无需域名和证书，推荐」「WS + TLS · 可以套 CDN」「Hysteria2 · UDP，弱网下更快」）以及标签（需要证书 / 需要域名 / UDP）。
- 选好模板后表单分两部分：「基本」（端口、SNI）和「高级（JSON）」，后者默认折叠。

## 7. 命令面板（P0）

- 结果按区块分组：页面、用户、节点、操作，每组有小标题。
- 没有输入时显示「最近访问」（存在 localStorage，最多 5 条）加常用操作。
- 选中用户后，支持次级动作：`Enter` 打开详情，`⌘C` 直接复制订阅链接（底部提示条注明）。
- 底部提示：`↑↓ 选择 · ↵ 打开 · ⌘C 复制订阅 · esc 关闭`。
- 动效见 §1.2。

## 8. 其它细节

- 相对时间统一使用 `<time>` 元素，悬停显示具体时间。（P1）
- 表格在手机端转成卡片列表：用户和事件两张表必须做，其余表格允许横向滚动。（P1）
- `?` 打开快捷键帮助弹窗。（P1）
- 危险操作的确认弹窗：主按钮使用 danger 样式，文案写清后果和影响数量；批量删除需要输入数字确认。（P0）
- 表单有未保存修改时，关闭弹窗或抽屉需要二次确认。（P1）

## 9. 验收清单（实现 agent 自测）

1. 打开和关闭用户抽屉、新建用户弹窗、⌘K、任意下拉、Toast，都能看到**进场和出场**动画；在 DevTools 里开启 reduced motion 后，位移动画消失但仍然有淡入淡出。
2. 用户页：
   - 筛选「即将到期」后结果正确，URL 中带有筛选参数。
   - 勾选 3 个用户后批量「续期 30 天」，一次请求完成，toast 可撤销，撤销后恢复原值。
3. 详情抽屉中按 `j` / `k` 切换用户，抽屉不会重新滑入。
4. 新建用户成功后，在弹窗里直接看到订阅链接和二维码。
5. 修改分组后，toast 从「正在下发」变为「✓ 已在所有节点生效」。
6. 顶栏同步指示器：手动 kill 节点进程后，60 秒内显示异常。
7. 添加节点向导：在本地执行 enroll 和 run 后，向导自动推进到「已连接 ✓」。
8. `go test ./internal/... ./test/`（tags `with_quic,with_utls,with_acme`）通过，新增的批量接口有测试；`npx tsc -b && pnpm build` 通过。

## 10. 上一轮 review 遗留问题（一并修复，P0）

- **订阅自助页** `internal/master/subpage.html`：在 http 下（拿不到 clipboard API）复制节点链接时，实际复制的是订阅链接。需要改成临时 textarea 的回退方案，复制当前要复制的那段文本。
- **3x-ui 导入页**：修改 JSON 或切换节点后，旧的预览没有清空，「导入」按钮仍然可点；错误要在卡片内显示，不能只弹 toast；文件选择器要换成自定义样式的中文按钮。
- **缺少 `onError` 的 mutation**：用户的删除和踢下线、节点 token 和删除、入站删除、Host 开关和删除、分组删除、模板丢弃草稿、API token 删除、开启 2FA、关闭实时连接。建议统一做一个 `useAction` 封装：自带 pending 状态、错误 toast 和缓存失效。
- **缓存失效遗漏**：保存分组后要刷新 `inbounds`；入站切换开关或删除后要刷新 `nodes`；用户变动后要刷新 `groups`（用户计数）。
- **375px 下横向溢出**：入站表、订阅页 Host 表、抽屉里的订阅访问表（来源 IP 被截断换行）、API token 表。处理方式：表格容器加 `overflow-x-auto`，单元格 `whitespace-nowrap`；用户表和事件表按 §8 改成卡片布局。
- **模板「基本」卡片**：三个 Select 的标签换行高度不一致。改成短标签，把说明文字放进 `description`。
- **批量创建**：手机上不要用 3 列栅格；数量超过 500 时在前端直接拦截。
- **文案**：
  - 入站页副标题改为「分组内的用户会下发到该入站」。
  - 删除分组的确认文案要算准「只属于该分组的用户数」，可以由前端根据用户的 group_ids 计算。
  - 通知页的「点左侧保存」改成「点下方保存」，或者把保存按钮放进卡片头部。
- **事件页**：同时有节点名和用户名时加分隔符；手机上改成两行布局。
- **缺少二次确认**：「断开筛选出的 N 条」（实时连接）、「丢弃草稿」（模板）。
- 模板仍被节点使用时，删除按钮要禁用，并用 tooltip 说明原因。
- 流量页维度 chips 补上 `aria-pressed` 和 focus ring；表格里的 Switch 传入 `label`。
- 筛选工具栏（用户页、实时连接页）的控件对齐：统一不显示可见 label，用 `aria-label`；或者全部显示 label。
- 收尾时检查深色主题、768px 宽度和登录页。
- 删掉测试遗留的用户 `zzb01` 和 `zzb02`（通过 API 或 UI 删除即可）。
